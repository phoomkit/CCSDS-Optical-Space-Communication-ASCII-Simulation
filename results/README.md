# Result locations

- `figures/` and `data/` contain the current report results, including the
  convolutionally coded versus uncoded comparison.
- New interactive program runs are written to timestamped subdirectories such
  as `20261004_191424_619314_hello-coded/`; each contains its own metadata.
- The CSV, JSON, TXT and PNG files directly under `results/` are legacy
  uncoded outputs retained from the earlier project version.  They are not the
  current ECC report results and can be archived or removed separately after
  review.
